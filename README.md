# Shaxda Bisha — Xalane vs Macawisley

Single-page web app oo bil kasta u qaybiya 16 ciyaartoy laba koox oo siman (8 vs 8).

**Fur:** `index.html` — hal file, backend ma leh, internet uma baahna (marka laga reebo CDN-ka).

## Sida ay u shaqeyso

- **Qaybinta siman** — grade kasta (A/B/C/D) waxaa lagu qasaa si random ah, 2 koox walba. Koox kastaa waa **2A + 2B + 2C + 2D** = 8 ciyaartoy.
- **Hal mar bishii** — marka shaxda la sameeyo way xirmaysaa. Ma jiro badhan dib-u-qasid ah. Bisha cusub ayay mar kale furmaysaa.
- **Kabtan** — ciyaartoyga Grade A ee dhibcaha ugu badan leh koox kasta.
- **Bisha shaxda** — marka bishu dhammaanayso (3 maalmood ama ka yar) si toos ah ayay ugu gudubtaa bisha soo socota.
- **Wax ka beddel Grade-yada** — grade iyo dhibco waa la beddeli karaa; grade kastaa waa inuu leeyahay afar (4) ciyaartoy.
- **Maamulka** — bisha shaxda ayaa laga beddeli karaa, iyo furitaan (reset) haddii khalad dhaco.
- **Soo deji PDF** — A4 vector PDF ah (sawir maaha), qoraalka waa la doortaa, ~28 KB.

Dhammaan xogtu waxay ku kaydsan tahay `localStorage` ee browser-ka — server ma jiro, isku-xirid qalab kale ma jirto.

## Tignoolajiyada

HTML + Tailwind (CDN) + JavaScript · jsPDF (CDN) PDF-ka.
